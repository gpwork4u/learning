Transformer 區塊The Transformer Block

注意力只是零件之一。這一章把它裝回整台機器：LayerNorm、多頭注意力、前饋網路，以及貫穿全部的殘差流——再看這個區塊如何被複製數十次、堆成一個大型語言模型。

      § 4.1一個區塊裡有什麼

      一個 Transformer 區塊只做兩件事：先讓 token 彼此交流（注意力），再讓每個 token 各自思考（前饋網路）。兩件事都以「加回去」的方式寫進一條主幹上。

      每個子層前面都先做一次 LayerNorm，把向量的數值尺度拉回穩定範圍；子層算完的結果不是取代輸入，而是加到輸入上——這條讓原始資訊一路暢通的主幹，就叫殘差流。

      註 · pre-norm vs post-norm

      原始 Transformer 是 x = LN(x + Sublayer(x))。把 LN 移到子層前面（x = x + Sublayer(LN(x))）後，殘差主幹上完全沒有任何運算擋路，深層網路的梯度能直接流回底層，因此幾乎所有現代 LLM 都採用 pre-norm。

      § 4.2殘差流：模型的共用記事本

      把殘差流想成一條寬度固定的河。每一層都從河裡讀出目前的內容，算完後把一點新資訊寫回河裡。沒有任何一層會把河水整個換掉——所以第 1 層寫下的東西，第 40 層仍然讀得到。

      這也解釋了為什麼深層網路訓練得起來：梯度可以沿著「加法」這條捷徑一路傳回最底層，不會在幾十層的非線性中消失。

      § 4.3前饋網路：每個 token 的私人思考

      注意力負責「蒐集」，前饋網路（FFN，也叫 MLP）負責「加工」。它對每個位置分別套用同一個小網路，token 之間在這裡完全不交流：

      FFN(x) = W₂ · GELU(W₁x + b₁) + b₂
      // W₁：d → 4d（升維）　W₂：4d → d（降維）

      一個有用的直覺是把 FFN 看成鍵值記憶體：W₁ 的每一列像一把「鍵」，偵測輸入是否符合某種模式（例如「前面提到了法國首都」）；被激活的神經元再透過 W₂ 對應的「值」，把相關知識（「巴黎」）寫回殘差流。模型大部分的事實性知識，被認為就存放在這些 FFN 權重裡。

      註

      FFN 的參數量是注意力的兩倍（8d² 對 4d²），所以一個區塊裡大約三分之二的參數都在 FFN。許多新模型把 GELU 換成 SwiGLU，結構略有不同，但「升維—非線性—降維」的精神不變。

      § 4.4堆疊 N 層，最後變成 logits

      完整的模型其實很單純：嵌入 → N 個相同結構的區塊 → 最後一次 LayerNorm → unembedding。最後一步把殘差流上的向量乘以一個 d × V 的矩陣（常和嵌入矩陣共用權重），為詞彙表中每個 token 打一個分數，這組分數就是 logits，第 05 章會把它變成機率並取樣。

      參數幾乎都集中在區塊裡：每個區塊的注意力有 WQ、WK、WV、WO 四個 d×d 矩陣（4d²），FFN 有兩個 d×4d 矩陣（8d²），合計約 12d²。

      § 4.5本章重點

      1. 一個區塊 = 注意力（token 間交流）+ 前饋網路（各自加工），兩者前面各有一個 LayerNorm。
      2. 子層的輸出是「加」回殘差流，而不是取代它；這讓資訊與梯度都能暢通地穿越數十層。
      3. 殘差流像共用記事本：每一層讀取、再寫入一點新資訊，寬度始終是 dmodel。
      4. FFN 先升維 4 倍再降維，可視為鍵值記憶，承載大量事實性知識，也占約三分之二的區塊參數。
      5. 模型 = 嵌入 → N 個區塊 → LayerNorm → unembedding；參數量約為 12·N·d² + V·d。
