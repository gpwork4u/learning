訓練與對齊Training & Alignment

前面五章拆解了模型「怎麼算」，這一章回答「參數從哪裡來」。從一個最單純的目標——猜對下一個 token——出發，看梯度下降如何一步步調整數十億個參數，以及模型如何從「會續寫」變成「會回答」。

      § 6.1學習目標：猜對下一個字

      大型語言模型的訓練目標出奇地單純：給它一段文字的前半，要它預測下一個 token，然後看它猜得有多準。

      第 05 章說過，模型每一步都會輸出一個機率分布。訓練時我們手上有正確答案，所以只要看正確答案拿到的機率 p：p 越高越好。把它轉成「越小越好」的數字，就是交叉熵損失：

      Loss = −log p(正確的 token)
      // p = 1 → 損失 0；p 趨近 0 → 損失趨近無限大

      整份訓練資料的損失，就是每一個位置的 −log p 取平均。注意曲線左側非常陡：模型對正確答案「完全沒想到」時，會受到最重的懲罰，也帶來最強的學習訊號。

      § 6.2梯度下降與學習率

      損失是所有參數的函數。想像一片地形：位置是參數的值，高度是損失。訓練就是蒙著眼睛下山——每一步摸摸腳下的坡度（梯度），往下坡方向走一小步：

      θ ← θ − η · ∇Loss(θ)
      // η（eta）就是學習率：每一步要跨多大

      那數十億個參數的梯度怎麼算？靠反向傳播：從損失往回，用連鎖律一層層算出「這個參數稍微變大，損失會變多少」——就像追查一份錯誤報告，把責任按比例分攤回每一層。

      註

      實務上不會一次看完整份資料才走一步，而是每次抽一小批（mini-batch）估計梯度，稱為隨機梯度下降（SGD）。大型模型通常搭配 AdamW 最佳化器，並在訓練初期「暖身」逐步調高學習率、後期再慢慢降低。

      § 6.3從預訓練到對齊

      只靠「猜下一個字」訓練出來的模型很博學，但它只會續寫：你問它問題，它可能接著寫出更多問題。要變成能對話的助手，現代 LLM 通常經過三個階段：

      1. 預訓練（Pretraining）——在數兆 token 的網頁、書籍、程式碼上預測下一個 token，學到語言與世界知識。佔掉絕大部分的算力。
      2. 指令微調（Supervised Fine-Tuning, SFT）——用人工撰寫的「指令 → 回答」示範繼續訓練，學會對話的格式與角色。
      3. 偏好對齊——讓人比較兩個回答哪個較好。RLHF 先用這些比較訓練一個獎勵模型替回答打分，再用強化學習提高分數；DPO 則跳過獎勵模型，直接用偏好對調整機率。

      獎勵模型到底學到了什麼？它沒有讀過任何「好回答的定義」，只看過一對對「人比較喜歡哪個」的紀錄。下面換你當那位標註員。

      這正是 RLHF 的核心交換：人只需要做「比較」這件相對容易的事，獎勵模型把成千上萬次比較濃縮成一個打分函數，強化學習再拿這個分數去推動語言模型。DPO 則省略中間的打分函數，直接用同一批偏好對調整模型的機率。也因為如此，標註員的偏好會原封不動地變成模型的偏好——如果標註時總是偏愛長篇大論或客套話，模型就會學到冗長與諂媚。

      § 6.4規模定律：越大越好，但有規律

      2020 年起的一系列研究發現：只要資料與算力跟得上，模型的損失會隨著參數量 N、資料量 D、算力 C 以冪次律平滑下降——在對數座標上幾乎是一條直線。

      Loss(N) ≈ (Nc / N)α
      // 參數每放大 10 倍，損失按固定比例下降（α 約 0.07，示意）

      規模定律解釋了為什麼過去幾年模型越做越大；但它描述的是損失，不保證某項具體能力何時出現，也不代表資料用不完——高品質文本的供給，正逐漸成為新的瓶頸。

      § 6.5本章重點

      1. 預訓練的目標只有一個：最小化預測下一個 token 的交叉熵損失 −log p。
      2. 梯度下降沿著損失下降最快的方向更新參數；反向傳播用連鎖律算出每個參數的梯度。
      3. 學習率太小走得慢，太大會震盪甚至發散；上限由最陡的方向決定，實務上用 AdamW 與學習率排程來平衡。
      4. 預訓練帶來知識，SFT 教會對話格式，RLHF / DPO 讓回答貼近人類偏好。
      5. 規模定律顯示損失隨參數、資料、算力以冪次律平滑下降，讓大模型的表現可以被預估。
