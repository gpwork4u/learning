生成與取樣Decoding & Sampling

模型每一步只輸出一張「下一個 token 的機率表」，真正決定寫出哪個字的是解碼策略。這一章用四張圖版（其中一張讓你親手捏分布）拆開這最後一哩路：機率從哪來、怎麼一次一個字接下去，以及溫度、Top-k、Top-p 如何改變輸出的性格。

      § 5.1從 logits 到機率分布

      經過一層層 Transformer 區塊後，模型在最後一個位置輸出一個很長的向量——長度等於詞彙表大小，常見是 3 萬到 20 萬。這些數字叫 logits，是還沒正規化的分數。

      logits 可以是任何實數，彼此加起來也不等於 1。要把它們變成「每個 token 被選中的機率」，用的是第 03 章就見過的 softmax，只是這裡多了一個旋鈕：溫度 T。

      pᵢ = exp(zᵢ / T) / Σⱼ exp(zⱼ / T)
      // T = 1 就是標準 softmax；T 越小分布越尖，T 越大分布越平
      註

      機率分布本身是確定的：同樣的前文、同樣的模型，算出來的 logits 永遠一樣。同一個問題每次回答不同，是最後「抽樣」這一步造成的，不是模型改變了想法。

      § 5.2一次一個 token：自迴歸生成

      LLM 並不會一口氣寫出整段話。它預測下一個 token 的分布、從中挑一個、把它接回輸入的尾端，再用變長的序列預測下一個……直到產生結束符號或達到長度上限。這種「自己的輸出變成自己的輸入」的方式叫自迴歸。

      每一步都要重新處理整段前文聽起來很浪費。實作上會用 KV cache 把先前 token 在每一層算過的 K、V（第 03 章）存起來，新 token 只需要算自己那一份——這也是長對話會吃掉大量 GPU 記憶體的原因。

      自迴歸還有一個重要後果：錯誤會累積。一旦早期挑了一個不太恰當的 token，後面所有預測都建立在它之上，而模型沒有「回頭修改」的機制，只能順著寫下去。

      § 5.3解碼策略：從分布中挑哪一個？

      Greedy：永遠挑最高的

      最直覺的做法是每步都挑機率最高的 token。結果完全可重現，但常常平淡，而且容易陷入重複迴圈。在 FIG 5.3 切到 Greedy，不管按幾次重設，都會得到同一句話。

      溫度：讓分布變尖或變平

      把 logits 先除以 T 再做 softmax。T < 1 會放大分數之間的差距，高分者更集中；T > 1 會縮小差距，冷門候選也分到機率。T 趨近 0 時就等於 Greedy。

      Top-k 與 Top-p：先砍掉長尾

      就算整體溫度適中，詞彙表裡仍有數萬個機率極小但不為零的 token，累積起來被抽中的機會並不小。Top-k 只保留機率最高的 k 個候選；Top-p（又稱 nucleus sampling）則保留「累積機率剛好達到 p」的最小集合。

      兩者的差別在於：Top-k 的候選數是固定的，Top-p 會隨模型的信心自動伸縮——模型很有把握時，可能只剩一兩個候選；模型猶豫時，候選會變多。回到 FIG 5.1，把 Top-p 拉到 0.8，再分別把溫度調低與調高，觀察「保留候選」的數字如何改變。

      策略做法適合風險
      Greedy每步挑機率最高者短答案、需要可重現的任務單調、容易重複
      溫度 Tlogits ÷ T 再 softmax調整整體的冒險程度太高會語無倫次
      Top-k只留前 k 名再重新正規化砍掉離譜的長尾k 固定，不隨信心調整
      Top-p留累積機率達 p 的最小集合通用預設（p ≈ 0.9）p 太大仍會抽到長尾

      實務上這些方法會串起來用，常見順序是：溫度 → Top-k → Top-p → 抽樣。FIG 5.1 的控制台就是照這個順序計算的。

      § 5.4重複與幻覺的直覺

      為什麼會一直重複？

      低溫或 Greedy 時，模型每步都走最「安全」的路。一旦某句話出現過一次，前文中就有了它，注意力會讓模型覺得「再說一次」很合理——形成自我強化的迴圈。常見的對策是 repetition / frequency penalty：降低已經出現過的 token 的 logits。

      為什麼會一本正經地胡說？

      取樣只保證輸出「看起來像是可能出現的文字」，不保證它是真的。當高溫或長尾讓一個錯誤的 token 被抽中，自迴歸會讓模型順著它編下去以保持通順（§ 5.2 的錯誤累積）。不過幻覺的根源主要在於模型被訓練來預測可能的文字而不是正確的事實（第 06 章），解碼策略只是把這個傾向放大或縮小。

      實務參考

      寫程式、事實問答：溫度 0–0.3。一般對話：0.7 左右搭配 Top-p 0.9。創意寫作、腦力激盪：0.9–1.1。數值依模型而異，先從預設值開始微調。

      § 5.5本章重點

      1. 模型每一步輸出整個詞彙表的 logits，softmax 之後才是機率分布；分布本身是確定的，隨機只發生在抽樣。
      2. 生成是自迴歸的：挑一個 token、接回輸入、再預測下一個；KV cache 讓這件事不必每步從頭算，但錯誤也會一路累積。
      3. Greedy 穩定但單調；溫度控制分布的尖銳或平坦，T → 0 等於 Greedy。
      4. Top-k 固定保留前 k 名，Top-p 依模型信心自動調整候選數量。
      5. 低溫容易重複、高溫容易離題；幻覺的根源在於模型學的是「可能的文字」而不是「事實」。
