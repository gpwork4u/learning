自注意力Self-Attention

一句話裡的每個 token，都要決定「該參考誰、參考多少」。這一章用四張圖版拆開注意力機制：先看效果，再看 Q、K、V 怎麼算，接著親手拖動查詢向量，最後看整張注意力矩陣與遮罩。

    圖版

      § 3.1「它」指的是誰？

      讀到「貓沒有跳上桌子，因為它太累了」，你會自然地把「它」連到「貓」；但只要把最後一個字換成「高」，「它」就變成了「桌子」。

      同一個字的意思，取決於它跟句子裡其他字的關係。上一章的嵌入向量只描述了 token 自己，還沒有任何上下文。自注意力就是讓每個 token 去「看」其他 token、把相關的資訊混進自己的表示裡的機制。

      § 3.2Q、K、V：查詢、鍵、值

      注意力的計算可以想成在圖書館找資料：

      • Query（查詢，q）——「我現在想找什麼？」由正在更新的那個 token 發出。
      • Key（鍵，k）——「我這裡有什麼？」每個 token 掛出的索引標籤。
      • Value（值，v）——「如果你選了我，我交給你的內容。」

      q 和每個 k 做點積得到相似度分數，經過 softmax 變成權重，再用這組權重把所有 v 加權平均——這就是該 token 的新表示。三個向量都是同一個嵌入 x 乘上三個不同的學習矩陣得到的。

      把整個過程寫成一行，就是 Transformer 論文裡的那條公式：

      Attention(Q, K, V) = softmax( QKᵀ / √dₖ ) · V
      // 除以 √dₖ：維度越高點積越大，softmax 會變得太尖銳，梯度消失

      公式背後只有兩個直覺：q 的方向決定它和哪個 k 最像，q 的長度決定 softmax 有多「果斷」。光看不如親手試試看。

      § 3.3注意力矩陣與因果遮罩

      把每個 token 當作查詢都算一次，就得到一張 n×n 的注意力矩陣：第 i 列是第 i 個 token 分配給所有 token 的權重。所有列可以用矩陣乘法一次平行算完，這是 Transformer 比 RNN 快的關鍵。

      像 GPT 這類生成式模型在訓練時要預測下一個字，不能偷看答案，所以會加上因果遮罩：第 i 個 token 只能看到自己和前面的 token，右上三角被設成 −∞，softmax 後變成 0。

      § 3.4多頭注意力

      單一組 Q、K、V 只能學到一種「關注方式」。多頭注意力（Multi-Head Attention）同時跑 h 組獨立的注意力，例如一個頭追蹤指代、一個頭看相鄰字、一個頭抓語法結構，最後把各頭的輸出串接起來再做一次線性投影。

      headᵢ = Attention(XWᵢQ, XWᵢK, XWᵢV)
      MultiHead(X) = Concat(head₁, …, headₕ) · WO
      註

      每個頭的維度通常是 dmodel / h，所以多頭並不會讓計算量變成 h 倍——只是把同樣的維度切成好幾份，各看各的。

      § 3.5本章重點

      1. 自注意力讓每個 token 依據上下文重新組合自己的表示，解決「同字不同義」。
      2. q·k 決定「看誰」，softmax 把分數變成權重，權重乘 v 決定「拿到什麼」。
      3. 除以 √dₖ 是為了讓 softmax 不要過度尖銳。
      4. 生成式模型使用因果遮罩，確保每個位置只看得到過去。
      5. 多頭注意力讓模型同時學到多種關係模式。
